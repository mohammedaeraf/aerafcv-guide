## 1. Learning Objective

By the end of this lesson, you should be able to:

- Understand why we must study the target job before writing a resume.
- Identify the important requirements in a job description.
- Understand a candidate's background, experience and career goals.
- Identify the matching skills and experience of a candidate.
- Recognise missing information that needs clarification.

## 2. Why Should We Understand the Target Job First?

A resume should not simply describe everything a candidate has done.

It should highlight the candidate's most relevant qualifications, skills and experience for the job they want.

Consider two candidates:

**Candidate A**
- BCA graduate.
- Knows HTML, CSS, JavaScript and React.
- Wants to apply for Junior Web Developer positions.

**Candidate B**
- BCA graduate.
- Knows HTML, CSS, JavaScript and React.
- Wants to apply for IT Support positions.

Although both candidates have similar educational backgrounds and technical skills, their resumes should be different because their target jobs are different.

**Remember:** A good resume is not just a record of a candidate's past. It is a professional document tailored to their next career opportunity.

## 3. What Is a Job Description?

A Job Description (JD) is a document published by an employer explaining the responsibilities, qualifications, skills and experience required for a particular position.

For example, consider this fictional job advertisement.

### Sample Job Description – Junior Frontend Developer

**Company:** ABC Technologies (fictional)  
**Position:** Junior Frontend Developer

**Responsibilities:**
- Develop and maintain responsive web pages.
- Work with HTML, CSS and JavaScript.
- Build user interfaces using React.
- Collaborate with other developers.
- Maintain and update existing website components.

**Required Skills:**
- Basic knowledge of HTML, CSS and JavaScript.
- Understanding of React.
- Knowledge of responsive web design.
- Familiarity with Git.
- Academic or personal web development projects.

**Preferred:**
- Knowledge of REST APIs.
- Previous internship experience.

This job description tells us what the employer is looking for.

Our job as resume writers is to identify which of these requirements the candidate can genuinely demonstrate.

## 4. How to Analyse a Job Description

Follow these five steps whenever you receive a job description.

### Step 1: Identify the Target Job Title

Find the exact position the candidate is applying for.

Examples:
- Junior Web Developer
- Office Administrator
- Sales Executive
- Recruitment Coordinator

The resume headline should reflect the candidate's actual target role and relevant background.

### Step 2: Identify Required Skills

Look for technical and professional skills mentioned in the job description.

Examples:

| Job Position | Relevant Skills |
|---|---|
| Web Developer | HTML, CSS, JavaScript, React |
| Office Administrator | MS Office, Documentation, Coordination |
| Sales Executive | Customer Service, Sales Communication, Negotiation |
| HR Coordinator | Communication, Scheduling, Record Management |

### Step 3: Identify Responsibilities

Understand what the candidate will be expected to do.

For example, an Office Administrator may be expected to:
- Maintain records.
- Prepare reports.
- Coordinate meetings.
- Handle correspondence.

These responsibilities help us identify which parts of the candidate's previous experience are relevant.

### Step 4: Identify Qualifications and Experience

Check whether the employer requires:
- A particular degree or qualification.
- A minimum number of years of experience.
- Specific certifications.
- Industry experience.
- Knowledge of particular tools or software.

Distinguish between mandatory requirements and preferred requirements.

### Step 5: Match Requirements with Candidate Evidence

Compare the job description with the information supplied by the candidate.

Do not assume that a candidate possesses a skill just because it appears in the job advertisement.

If information is missing, ask the candidate.

## 5. Practical Example – Matching Aisha's Profile with a Job

Let's use **Profile A – Aisha Rahman (Fresher)** from our training workbook.

### Candidate Information

- BCA graduate, 2026.
- HTML, CSS and JavaScript fundamentals.
- React basics.
- Git.
- Responsive design.
- Completed a Campus Events Portal project using React.
- No formal employment experience.

### Job Requirements vs Candidate Evidence

| Job Requirement | Candidate Evidence | Assessment |
|---|---|---|
| HTML | HTML fundamentals | Supported |
| CSS | CSS fundamentals | Supported |
| JavaScript | JavaScript fundamentals | Supported |
| React | React basics | Supported |
| Responsive Design | Listed as a skill | Supported |
| Git | Listed as a skill | Supported; clarify practical usage if needed |
| REST APIs | Not mentioned | Needs clarification |
| Internship Experience | No internship listed | Do not claim |

### What Should We Highlight?

For Aisha's resume, we should give priority to:

1. BCA education.
2. Relevant technical skills.
3. Campus Events Portal project.
4. Introductory React workshop.

We should not claim that Aisha has professional React development experience or REST API knowledge without confirmation.

### Example Resume Bullet

**Campus Events Portal**
- Built a responsive event-listing interface using React and sample data, implementing category-based filtering and event detail views.

This statement is based on the information provided in her profile.

Let's briefly consider the other three candidates.

- Customer handling.

- Communication.

**Writer's focus:** Show how her customer support experience and transferable skills are relevant to HR. Do not claim previous recruitment experience unless she confirms it.

## 7. Important Questions to Ask a Candidate

Before writing a resume, collect sufficient information.

Here are some useful questions:

1. What exact job title are you targeting?
2. Which industry or type of company are you interested in?
3. Do you have a job advertisement for the position?
4. Which skills do you use confidently?
5. What were your main responsibilities in your previous job?
6. Did you complete any projects, internships or professional training?
7. Can you provide examples of achievements or measurable results?
8. Are there any employment gaps or career changes we should understand?

**Professional Rule:** If an answer is vague, ask follow-up questions. Never fill missing information with assumptions.

## 10. Key Takeaways

- Always understand the target job before writing a resume.
- A job description helps identify the employer's expectations.
- Identify relevant skills, responsibilities and qualifications.
- Match job requirements with evidence from the candidate's profile.
- Highlight relevant information rather than including everything.
- Ask questions when information is incomplete or unclear.
- Never add skills, experience or achievements without candidate confirmation.
