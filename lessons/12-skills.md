# **Aeraf CV – Resume Writer Training Programme**

## **Day 12 – Writing an Effective Skills Section**

**Module:** Week 2 – Resume Sections\
**Duration:** 10–15 minutes

### **🎯 Learning Objective**

By the end of this lesson, you should be able to:

- Identify relevant skills from a candidate's background.
- Distinguish between technical, job-specific and transferable skills.
- Organise skills into meaningful categories.
- Tailor the Skills section to a target job.
- Avoid exaggerated, irrelevant or unsupported skill claims.

### **1. Why Is the Skills Section Important?**

The Skills section gives recruiters a quick overview of what a candidate can do.

It helps them identify whether the candidate possesses the capabilities required for the job.

For example, a Junior Web Developer may need HTML, CSS, JavaScript and React, while an Office Administrator may need documentation, spreadsheet management and meeting coordination skills.

A good Skills section should be:

- Relevant to the target job.
- Easy to scan.
- Organised into suitable categories.
- Supported by the candidate's education, training or experience.
- Honest about the candidate's actual proficiency.

**Remember:** The purpose is not to list as many skills as possible. It is to highlight the most relevant ones.

### **2. Three Main Categories of Skills**

**A. Technical or Hard Skills**

These are practical, teachable skills that can generally be demonstrated or assessed.

Examples:

- HTML, CSS and JavaScript
- Microsoft Excel
- React
- CRM systems
- POS billing
- Database management

**B. Soft Skills**

These describe how someone communicates, collaborates and approaches work.

Examples:

- Communication
- Teamwork
- Problem-solving
- Time management
- Adaptability
- Attention to detail

Soft skills are more convincing when supported by examples in the Work Experience section rather than simply listed.

**C. Job-Specific or Functional Skills**

These are capabilities directly related to a particular profession or role.

Examples:

| Target Role          | Relevant Skills                                          |
| -------------------- | -------------------------------------------------------- |
| Web Developer        | Frontend Development, Responsive Design, Git             |
| Office Administrator | Record Management, Documentation, Meeting Coordination   |
| Sales Executive      | Customer Service, Product Presentation, Order Processing |
| HR Coordinator       | Scheduling, Onboarding Support, Record Accuracy          |

Some skills may belong to more than one category. The important thing is to organise them in a way that makes sense to the recruiter.

### **3. How to Identify a Candidate's Skills**

Do not rely only on what the candidate writes in their initial questionnaire.

Look for skills in:

1. Academic qualifications and coursework.
2. Previous job responsibilities.
3. Projects and practical assignments.
4. Training programmes and workshops.
5. Achievements and contributions.
6. Tools and software the candidate has actually used.

**Example:**

A candidate says:

"I worked in an office. I maintained files, prepared letters, updated Excel sheets and coordinated meetings."

From this information, we can identify:

- Documentation
- Record Management
- Microsoft Excel
- Administrative Coordination
- Meeting Coordination

The candidate may also demonstrate organisation and communication skills through these responsibilities.

However, do not automatically claim advanced Excel proficiency just because the candidate has used Excel.

### **4. How to Organise the Skills Section**

Instead of presenting a long, unstructured list, group related skills together.

**Example – Junior Web Developer**

**Technical Skills**

- HTML
- CSS
- JavaScript
- React (Basic)
- Git

**Development Concepts**

- Responsive Design
- Frontend Development Fundamentals

This makes the section easier to scan.

**Example – Office Administrator**

**Administrative Skills**

- Record Management
- Documentation
- Meeting Coordination
- Office Administration

**Technical Skills**

- MS Word
- MS Excel
- MS Outlook
- Basic Document Management Systems

Avoid unnecessary categories if the candidate has only a few relevant skills. A simple list can be perfectly acceptable.

### **6. How Many Skills Should We Include?**

There is no fixed number that applies to every resume.

As a practical starting point:

- Include around 6–12 relevant skills when the candidate's experience supports them.
- Give priority to skills mentioned in the target job description.
- Remove skills that are outdated, irrelevant or unsupported.
- Avoid repeating the same skill in several categories.
- Do not fill the section with generic words simply to make it look longer.

A short, relevant Skills section is better than a long list of unrelated abilities.

### **7. Common Mistakes to Avoid**

**1. Listing too many skills**

A list of 30–40 skills may look impressive, but many may be irrelevant to the target role.

**2. Claiming expertise without evidence**

Do not describe a candidate as an expert in Excel, React or recruitment software unless their proficiency is supported.

**3. Using generic skills without examples**

Words such as hardworking, sincere and dedicated are not particularly useful as standalone skills.

**4. Mixing unrelated skills**

Avoid placing programming languages, communication skills and office administration capabilities in one confusing list.

**5. Repeating information unnecessarily**

If the same capability is already clearly demonstrated elsewhere, avoid excessive repetition.

**6. Inventing tools or technologies**

Never add software simply because it is commonly used in the candidate's industry.

**7. Using visual skill ratings without a reliable basis**

Avoid arbitrary progress bars such as "Excel – 90%" or "Communication – 95%". Such percentages are subjective and may mislead recruiters.

### **9. Small Assignment – Prepare Four Skills Sections**

Prepare a Skills section for each fictional candidate:

1. **Aisha Rahman:** Junior Web Developer.
2. **Rahul Shetty:** Office Administrator.
3. **Naveen Kumar:** Sales Executive.
4. **Priya Nair:** HR/Recruitment Coordinator.

For each candidate:

- Group related skills under suitable headings.
- Prioritise skills relevant to the target job.
- Use only information supported by the workbook.
- Distinguish technical skills from transferable or functional skills.
- Identify any additional skills you would need to verify with the candidate.

**Bonus Challenge:** Imagine Aisha is applying for a Frontend Developer position that specifically mentions React, JavaScript and Git. Reorder her Skills section to highlight the most relevant requirements first, without changing her actual proficiency.

### **Key Takeaways**

- Skills should be relevant to the target job.
- Understand the difference between technical, soft and functional skills.
- Use information from education, projects and employment to identify genuine skills.
- Organise related skills into clear categories.
- Avoid generic, irrelevant or unsupported claims.
- Never exaggerate proficiency.
